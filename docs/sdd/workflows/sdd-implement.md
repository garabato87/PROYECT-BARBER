# /sdd-implement

Uso:

```text
/sdd-implement STEP [N]
```

Implementar únicamente el Step aprobado.

Leer Specification, Plan, reglas y código relevante.

Cuando corresponda:

```text
RED → GREEN → REFACTOR → VERIFY
```

No modificar fuera del alcance del Step.

Verificar con comandos reales del proyecto.

Reportar archivos, cambios, tests, comandos, resultados, riesgos y estado.
